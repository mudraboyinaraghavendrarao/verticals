Image Vision

S.No Solution Description Preview link
1 Label Detection The Label Detection can detect and extract information about entities in an image, across a broad group of categories. Labels can identify general objects, locations, activities, animal species, products, and more.
2 Text Detection Text Detection detects and extracts text from any image. For example, a photograph might contain a street sign or traffic sign.
3 Ladmark Detection Landmark Detection detects popular natural and human-made structures within an image.
4 Logo Detection Logo Detection detects popular product logos within an image.
5 Safesearch Detection SafeSearch Detection detects explicit content such as adult content or violent content within an image. This feature uses five categories (adult, spoof, medical, violence, and racy) and returns the likelihood that each is present in a given image.
6 Emotion Detection Emotion Detection detects the emotion of the person in the image. This feature uses four categories (joy, anger, sorrow, and surprise.) and returns the likelihood that each is present in a given image.
7 Web Content Detection Web Content Detection detects Web references to an image.
8 Face Recognition Face Recognition detects and recognize the faces in the image.
9 Caption Generator Caption Generator generates the content in the image.
10 Human Pose Detection Human Pose Detection detect the pose of a human in the image.
